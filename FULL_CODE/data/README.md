# data/README.md
# TriageGuard – Synthetic Dataset

> **ALL DATA IN THIS DIRECTORY IS 100 % SYNTHETIC.**
> It was generated by `triageguard/data_gen.py` using `archetypes.yaml` and
> `lexicon.yaml`.  It has no connection to any real patient, hospital, or
> clinical event.
>
> **PLACEHOLDER**: Every distribution, threshold, and prior used to generate
> this data is a placeholder that must be reviewed by a licensed clinician and
> replaced with values derived from the official triage primer before any
> real-world use.
>
> **NOT CLINICALLY VALIDATED.  DO NOT USE FOR CLINICAL DECISIONS.**

---

## Files

| File | Rows | Description |
|---|---|---|
| `synthetic_intake.csv` | 30,000 | Patient intake form — features only, no labels |
| `hidden_labels.csv` | 30,000 | Ground-truth labels — **must be isolated from model training code** |
| `splits.csv` | 30,000 | Stratified train / calib / val / test assignments |

## `synthetic_intake.csv` — Column Reference

| Column | Type | Description | Notes |
|---|---|---|---|
| `patient_id` | string | Unique patient identifier (P000001 … P030000) | Synthetic |
| `age` | int | Age in years (0 = infant < 1 yr) | PLACEHOLDER distribution |
| `sex` | str | M / F | PLACEHOLDER prevalence |
| `bp_sys` | float or NaN | Systolic blood pressure (mmHg) | May contain injected errors (see below) |
| `bp_dia` | float or NaN | Diastolic blood pressure (mmHg) | May contain injected errors |
| `pulse` | float or NaN | Pulse rate (bpm) | May contain injected errors |
| `temp_c` | float or NaN | Temperature (nominally °C, but 2 % of rows contain a Fahrenheit value due to injected error) | PLACEHOLDER |
| `spo2` | float or NaN | Oxygen saturation (%) | 0.8 % of rows have values > 100 or = 0 |
| `complaint_text` | str | Free-text chief complaint in English, Telugu (Romanised), Hindi (Romanised), or code-mixed | SYNTHETIC — not real patient speech |
| `known_conditions` | str | Pre-existing medical conditions (semicolon-separated) | PLACEHOLDER pool |
| `medications` | str | Current medications | PLACEHOLDER pool |
| `arrival_time` | str | ISO-8601 datetime (YYYY-MM-DDTHH:MM:SS) | Synthetic daily curve, peak 9–12 AM and 5–7 PM |

### Injected vital errors (present in a fraction of rows)

| Error type | Rate (config) | Effect |
|---|---|---|
| `bp_zero` | 1.5 % | One of `bp_sys` or `bp_dia` is set to 0 |
| `bp_swapped` | 0.7 % | `bp_sys` and `bp_dia` are swapped |
| `temp_fahrenheit` | 2.0 % | True °C temperature is converted to °F and stored in `temp_c` |
| `spo2_invalid` | 0.8 % | `spo2` is set to 0 or to a value > 100 |
| `pulse_zero` | 0.5 % | `pulse` is set to 0 |
| `decimal_slip` | 0.5 % | A vital is divided by 10 (e.g. 120 → 12.0) |
| `vitals_missing` | 4.0 % | 1–2 vital fields set to NaN |

All rates are **PLACEHOLDER** values in `config.yaml`.

## `hidden_labels.csv` — Column Reference

> **ISOLATION RULE**: model code (`model_vitals.py`, `model_text.py`, `fusion.py`, …)
> must NEVER import or read `hidden_labels.csv` directly during training.
> Labels reach the model only via the train split of the merged intake + labels
> CSV, prepared by a separate pipeline step.

| Column | Type | Description | Notes |
|---|---|---|---|
| `patient_id` | string | Join key to `synthetic_intake.csv` | |
| `triage_level` | int (1–5) | Triage level after label noise | 8 % of non-emergency rows have ±1 noise |
| `clean_triage_level` | int (1–5) | Triage level before label noise | Guaranteed to satisfy the level mix target |
| `department` | str | Recommended department | One of 12 departments |
| `is_emergency` | bool | True if clean_triage_level ∈ {1, 2} | Never noised |
| `archetype` | str | Generating archetype name | From `archetypes.yaml` |
| `reporting_bias` | str | `none` / `under_report` / `over_report` | 12 % of emergencies under-report; 6 % of L4/5 over-report |
| `injected_errors` | str | Pipe-delimited error codes, or `none` | e.g. `bp_zero:bp_sys|missing:spo2` |

### Departments used

`Emergency/Casualty`, `General Medicine`, `Cardiology`, `Pulmonology`,
`Pediatrics`, `Obstetrics & Gynecology`, `Orthopedics`, `Surgery`,
`ENT`, `Ophthalmology`, `Dermatology`, `Psychiatry`

### Level definitions (PLACEHOLDER — pending official triage primer)

| Level | Name | Target prevalence |
|---|---|---|
| 1 | Resuscitation | ~0.5 % |
| 2 | Emergency | ~3.5 % |
| 3 | Urgent | ~25 % |
| 4 | Semi-urgent | ~40 % |
| 5 | Non-urgent | ~31 % |

## `splits.csv` — Column Reference

| Column | Type | Description |
|---|---|---|
| `patient_id` | string | Join key |
| `split` | str | `train` (60 %) / `calib` (15 %) / `val` (10 %) / `test` (15 %) |

Split is stratified by `is_emergency`.  The calibration split is guaranteed
to contain ≥ 150 emergency rows (required for Mondrian conformal calibration).

## Reproducibility

Running `python -m triageguard.data_gen --seed 42` always produces the same
output.  The random seed is set in `config.yaml` and propagated through a
single `numpy.random.default_rng(seed)` instance.

## Confusable Pairs

The following archetype pairs share similar complaint text but differ in vitals:

| Emergency archetype | Confusable non-emergency | Key differentiator |
|---|---|---|
| `acs_stemi` (L2) | `chest_pain_acidity` (L4) | Low BP + tachycardia + SpO2 < 95 vs all normal |
| `severe_asthma_attack` (L2) | `breathlessness_anxiety` (L4) | SpO2 < 93 vs SpO2 ≥ 97 |
| `stroke_major` (L2) | `migraine` (L4) | BP > 160 + age > 50 vs normal/mildly elevated BP + age < 55 |
| `sepsis_severe` (L2) | `fever_adult_mild` (L4) | BP < 90 vs BP ≥ 100 |
| `acute_abdomen` (L3) | `gastritis_gerd` (L4) | Fever + tachycardia vs afebrile + normal HR |

These pairs are intentionally constructed so that **text alone is insufficient
to separate them**; vitals and age carry the decisive signal.
